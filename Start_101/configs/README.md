# configs/

Put your saved IxNetwork configurations (`.ixncfg` or `.json`) here.

In the IxNetwork GUI: *File → Save As…* → `configs/<name>.ixncfg`. Then run:

```bash
python 02_load_saved_config.py configs/<name>.ixncfg
```

Lesson 06 also writes the running config to `results/lesson06_saved.ixncfg`.
You can copy that file here to reuse it.
